# 🎨 Sprite Gditor Lite

**Sprite Gditor Lite** es una herramienta de edición de sprites minimalista integrada directamente en el editor de Godot 4. Diseñada para prototipado rápido y ajustes de arte pixelado sin salir de tu flujo de trabajo.

Esta es una versión gratuita y simplificada de la suite completa de herramientas de **Capyd3v**.

## ✨ Características
* **Integración Total:** Se añade como una pestaña (dock) en tu panel lateral de Godot.
* **Herramientas de Dibujo:** Pincel con tamaño ajustable y selector de color integrado.
* **Gestión de Lienzo:** Creación de lienzos desde 8x8 hasta 128x128 píxeles.
* **Historial:** Soporte para Deshacer (Undo) y Rehacer (Redo) de hasta 30 pasos.
* **Control de Vista:** Zoom fluido y navegación en el canvas.
* **Exportación:** Guarda tus creaciones directamente como archivos `.png` en tu sistema de archivos.

## 🚀 Instalación

1.  Descarga el repositorio o la carpeta del plugin.
2.  Copia la carpeta `Sprite-Gditor-Lite` dentro de la carpeta `res://addons/` de tu proyecto de Godot.
3.  Ve a **Ajustes del Proyecto** -> **Plugins**.
4.  Busca "Sprite Gditor Lite" y marca la casilla **Activado**.
5.  ¡Listo! El editor aparecerá en el panel lateral derecho (o superior).

## 🛠️ Controles Rápidos
* **Click Izquierdo:** Dibujar.
* **Rueda del Ratón:** Zoom In / Zoom Out.
* **Botón Limpiar:** Resetea el lienzo al tamaño seleccionado.
